# GBD_GI_Conditions_rscript
his repository contains the R scripts and analytical pipeline for quantifying and forecasting the global burden of essential gastrointestinal (GI) surgical diseases. Based on the GBD2023_GI_Surgery_Protocol_v1.4.docx, the analysis evaluates GI surgical conditions from 1990 to 2023, with ARIMA forecasting projected out to 2035.
